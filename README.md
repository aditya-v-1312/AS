# A Digital Love Story — Aditya & Shruti ❤️

> *"It was never planned, but it became everything. ♡"*

A romantic, interactive 3-month anniversary website celebrating the journey of Aditya and Shruti.

## ✨ Features
- **The First Impression**: Emotional opening screen with a live relationship counter.
- **Our Story**: Heartfelt chapter narrating how unexpected moments turned into home.
- **Scrapbook Photo Gallery**: Interactive Polaroid gallery featuring memories with washi tape, handwritten notes, category filters, and a click-to-expand lightbox.
- **A Letter for My Girl**: Vintage parchment love letter with custom postage stamps and wax seal.
- **Little Things I Love About You**: 9 interactive flip cards revealing reasons Aditya loves Shruti.
- **Our Little Timeline**: 7 milestones from the day we first met to 3 months of us.
- **The Little Envelope Surprise**: An animated keepsake envelope revealing a private note whenever she misses him.
- **Our Little Forever**: Grand finale celebration with interactive confetti.
- **Romantic Audio Player**: Floating uncopyrighted music player with procedural acoustic chords and MP3 support.
- **Heart Cursor**: Delicate floating heart trail on desktop.

## 🚀 Running Locally
```bash
cd site
npm install
npm run dev
```

Built with React, TypeScript, Tailwind CSS, and Vite.
